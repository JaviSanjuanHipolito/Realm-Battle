# ¿Qué es esto?

Realm Battles es un juego de peleas por turnos con estilo pixel para jugar en local con un amigo. Aquí no gana el que pulse más rápido, gana el que piense mejor: cada turno tienes que decidir si atacas, te defiendes o te curas, y un mal cálculo puede costarte la partida (y la amistad).

## Personajes

Cada personaje tiene estadísticas únicas, así que elegir bien ya es parte de la estrategia.

## Cómo se juega
Regístrate o inicia sesión.
Elige tu personaje (y tu amigo el suyo).
En cada turno, elige una acción:
Atacar para quitarle vida al rival
Defender para reducir el daño que recibes
Curar para recuperar vida

Gana quien deje al otro sin vida. El resultado se guarda y suma en el ranking.

## Características
Combate por turnos basado en estrategia
6 personajes con estadísticas únicas
Registro e inicio de sesión de usuarios
Ranking de jugadores
Estilo visual pixel
Entorno dockerizado

## Tecnologías
Backend: PHP
Base de datos: MySQL (usuarios, personajes y estadísticas)
Frontend: HTML + CSS
Entorno: Docker y Docker Compose
